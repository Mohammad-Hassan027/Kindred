# Kindred | Next.js Social Impact Template

[![Live Demo](https://img.shields.io/badge/Live-Demo-emerald?style=for-the-badge)](https://kindred-eight-gamma.vercel.app/)

**Kindred** is a modern, minimalistic website template designed for international nonprofits to bridge the gap between discovery and social impact. Built for the **Crowdera Next.js UI/UX Hackathon**, it focuses on "relational giving" by moving away from transactional interfaces to an impact-first experience.

---

## 🌟 The "Kindred" Concept

Kindred was born from the idea that nonprofits live on trust and transparency. The template is engineered to humanize the donation process:
- **Relational over Transactional:** Shifting the focus from "giving money" to "creating impact."
- **Soft Minimalism:** A design aesthetic that uses warm whites and deep emeralds to evoke a sense of calm, trust, and growth.
- **Mobile-First Empathy:** Ensuring that the storytelling experience is just as powerful on a smartphone as it is on a desktop.

## 🚀 Key Features

### 1. Dynamic Impact Calculator
The centerpiece of the donation experience. As users adjust their donation amount, they see real-time feedback on exactly what their contribution provides (e.g., "$50 = 10 meals").

### 2. Impact-First Discovery
Instead of traditional listings, the "Programs" page uses a "Problem-Solution-Impact" layout that tells a story before asking for support. It includes advanced filtering by category and urgency.

### 3. Trust & Transparency Dashboard
An interactive section on the About page featuring a custom SVG Donut Chart that visualizes fund allocation, ensuring donors know exactly where their money goes.

### 4. High-Conversion Donate Flow
A single-page, frictionless donation form with quick-select amounts, recurring gift toggles, and clear trust signals to maximize conversion.

### 5. Smooth Micro-Interactions
Subtle animations powered by **Framer Motion** that provide tactile feedback and create an emotional connection with the user.

## 📦 Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Mohammad-Hassan027/Kindred.git
   cd Kindred
   ```

2. **Install dependencies:**
   ```bash
   pnpm install
   ```

3. **Run the development server:**
   ```bash
   pnpm dev
   ```

4. **Build for production:**
   ```bash
   pnpm build
   ```

## 🏗️ Architecture

The project follows a modular and scalable structure:
- `app/`: Next.js App Router for routing and server-side logic.
- `components/`: Reusable UI components, following Atomic Design principles.
- `lib/`: Shared utilities, data models, and mock datasets.
- `hooks/`: Custom React hooks for shared logic (e.g., scroll reveal).
